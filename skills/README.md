# Music Production Intelligence Skills

This folder contains Claude skills that provide advanced music production intelligence for creating professional-grade techno tracks in the style of Charlotte de Witte and Adam Beyer.

## Skills Overview

### Core Intelligence Skills
1. **arrangement-intelligence.md** - Understands energy curves, tension/release, and when elements should enter/exit
2. **automation-composer.md** - Creates intelligent parameter automation for filters, volumes, and effects
3. **sound-design-layering.md** - Handles multi-sample layering and sound mangling techniques
4. **mix-analysis.md** - Analyzes frequency conflicts and suggests mixing decisions
5. **groove-timing-intelligence.md** - Applies micro-timing, polyrhythms, and groove psychology

### Supporting Skills
6. **reference-track-analyzer.md** - Learns from actual Charlotte de Witte/Adam Beyer tracks
7. **scene-transition-composer.md** - Creates intelligent transitions between scenes
8. **performance-macro-builder.md** - Builds live performance controls

## How These Skills Work

Each skill provides:
- **Context awareness** - Understands the current state of the Ableton session
- **Decision-making logic** - Makes musical choices based on genre conventions
- **Execution instructions** - Provides step-by-step actions using Ableton MCP tools
- **Quality validation** - Checks if the output matches professional standards

## Integration with Ableton MCP

These skills work alongside the Ableton MCP to:
1. Analyze the current session state
2. Make intelligent production decisions
3. Execute changes through MCP tools
4. Validate the results

## Usage

These skills are automatically loaded by Claude Code when working on music production tasks in this project.
