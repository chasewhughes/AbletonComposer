# Arrangement Intelligence Skill

## Purpose
Provides professional-grade arrangement intelligence for peak-time techno production, specifically emulating Charlotte de Witte and Adam Beyer's dynamic, constantly-evolving style rather than predictable intro-build-drop structures.

## Core Principles

### The 16-Bar Rule
All changes must occur in multiples of 8 or 16 bars to remain DJ-friendly. Never introduce changes at odd bar counts.

### Energy Curve Philosophy
Instead of linear progression (quiet → loud → quiet), create **overlapping energy waves**:
- Constant tension/release cycles every 16-32 bars
- When one element builds, another pulls back
- Never let the track become static or predictable
- Avoid obvious "breakdown → drop" patterns

### The Charlotte de Witte Approach
Based on her production philosophy emphasizing dancefloor dynamics and crowd energy reading:
- Every 16 bars must have micro-variations (fills, glitches, filter sweeps)
- Major changes every 32 bars (add/remove element, shift pattern)
- False drops and subverted expectations to maintain tension
- Stripped-back and dark aesthetic (less is more)

## Arrangement Decision Framework

### Scene Duration Calculator
```
Minimum scene length: 16 bars (32 beats at 130 BPM = ~14.7 seconds)
Standard scene: 32 bars (~29.5 seconds)
Extended scene: 48-64 bars for peak moments
```

### Element Introduction Strategy

**Rule 1: Additive Layering with Subtraction**
When adding a new element, consider removing or filtering another:
- Add open hats → Reduce bass filter cutoff
- Add stab lead → Drop out atmosphere temporarily
- Add ride cymbal → Pull back closed hats volume

**Rule 2: Frequency Space Management**
Before introducing elements, ask:
- What frequency range does this occupy?
- What existing elements conflict?
- Should something be filtered/EQ'd to make room?

**Rule 3: The "Hunger Principle"**
Create desire by withholding:
- Don't give the full bass until bar 32+
- Keep stab filtered until bar 48
- Hold back the ride cymbal until peak moments
- Remove kick entirely for 16 bars to create anticipation

### Scene-by-Scene Intelligence

#### Scene 1: Immediate Impact (Bars 1-32)
**Charlotte de Witte style:** Hard start with groove
- Elements: Kick + Bass + Minimal Hats
- Philosophy: "Start strong, not quiet"
- Variation: Add tiny percussion at bar 17
- Goal: Establish hypnotic groove immediately

#### Scene 2: First Layer (Bars 33-64)
**Add ONE element, not everything**
- Option A: Add filtered stab (keep it dark/mysterious)
- Option B: Add open hats with swing (rhythmic complexity)
- DO NOT: Add both stab AND atmosphere AND texture
- Goal: Introduce one point of interest

#### Scene 3: False Build (Bars 65-96)
**Create expectation but don't deliver**
- Add riser FX from bar 80-96
- Add texture/atmosphere
- Filter automation begins (high-pass drums)
- At bar 96: DON'T drop everything - subvert it
- Goal: Manipulate expectations

#### Scene 4: The Breakdown Fake-Out (Bars 97-128)
**Adam Beyer technique:** Remove kick/bass BUT keep energy
- Remove: Kick, Bass (the obvious "breakdown")
- Keep: Hats with groove, atmosphere, vocal (if available)
- Add: White noise, textures, tension elements
- Goal: Create "vacuum" feeling before real impact

#### Scene 5: False Drop (Bars 129-160)
**Kick returns but filtered/altered**
- Bring back kick with high-pass filter (not full)
- Bass in half-time or heavily filtered
- Add unexpected element (industrial texture)
- Goal: "That wasn't the real drop"

#### Scene 6: The REAL Peak (Bars 161-208)
**Maximum energy - but evolved**
- All elements active BUT with variations
- Ride cymbal at full velocity
- Bass filter fully open
- Stab pattern changed (not the same as Scene 2)
- Add polymetric percussion for hypnotic depth
- Goal: Payoff with evolution

#### Scene 7: Maintain Energy with Variation (Bars 209-256)
**Charlotte de Witte principle:** Don't cool down, EVOLVE
- Swap polymetric patterns (5/16 becomes 7/16)
- Change bass pattern (different rhythm, same notes)
- Filter automation creates movement
- Keep ride cymbal (maintain energy)
- Goal: Variation not reduction

#### Scene 8: DJ Tool Outro (Bars 257-288)
**Professional exit**
- Strip to: Kick + Bass + Minimal Hats
- Remove: All FX, atmosphere, stabs
- Keep groove locked for next DJ
- Goal: Clean mix-out point

## Automation Intelligence

### Filter Sweep Timing
```
Build section: Start sweep 16 bars before change
  - Bar 80: Start at 20Hz
  - Bar 88: Reach 300Hz (halfway)
  - Bar 96: Snap to 20Hz at scene change

Peak section: Slow LFO modulation
  - 1/2 bar frequency (creates breathing)
  - Range: 200Hz - 800Hz
```

### Volume Automation Strategy
```
Atmosphere/Texture elements:
  - Fade IN: 8 bars minimum
  - Fade OUT: 4 bars (faster exit creates urgency)

Riser FX:
  - Start: 16 bars before change
  - Volume: -inf to -6dB (don't overpower)
  - High-pass: Automate 20Hz → 8kHz
```

### Reverb Throws
Create space before transitions:
```
Bar before scene change:
  - Boost reverb send 0% → 80% over 1 bar
  - Add delay feedback burst
  - Creates "wash" effect
```

## Quality Validation Checklist

Before finalizing arrangement:

- [ ] Every scene is 16, 32, 48, or 64 bars (DJ-friendly)
- [ ] No two consecutive scenes feel identical
- [ ] At least one "false drop" or expectation subversion exists
- [ ] Elements don't all enter/exit simultaneously
- [ ] Frequency space is managed (no constant masking)
- [ ] There's at least one 16-bar section without kick (creates contrast)
- [ ] Peak moment has ALL elements but with evolved patterns
- [ ] Outro is clean and minimal for DJ mixing
- [ ] Total track length is 6-8 minutes (club standard)
- [ ] Energy never fully drops - it shifts and evolves

## Integration with Ableton MCP

### Before making changes:
1. Get session info to understand current state
2. Get track info for all tracks to know what elements exist
3. Get clip info to understand current scene contents

### When arranging:
1. Create clips in strategic scenes (not all scenes)
2. Use clip start/end markers for variations
3. Apply groove to percussion for human feel
4. Automate filters for movement
5. Configure sends for spatial depth

### Validation:
1. Check that scenes progress logically
2. Verify no frequency conflicts
3. Ensure automation creates movement
4. Test energy curve feels constant but evolving

## Example Decision Flow

```
User: "Arrange the track to sound like Charlotte de Witte"

Step 1: Analyze current tracks
  - Found: Kick, Bass, Hats (Closed/Open), Stab, Atmosphere, Ride

Step 2: Calculate arrangement
  - 130 BPM, 8 scenes, 32 bars each = 256 bars total (~6 min)

Step 3: Scene content decisions
  Scene 1 (1-32): Kick + Bass + Closed Hats ONLY
    → Creates hunger for more elements

  Scene 2 (33-64): + Open Hats + Filtered Stab
    → Add swing, keep stab mysterious

  Scene 3 (65-96): + Atmosphere + Riser (from bar 80)
    → Build expectation

  Scene 4 (97-128): REMOVE Kick/Bass, KEEP Hats/Atmo
    → False breakdown

  Scene 5 (129-160): Kick returns FILTERED, Bass half-time
    → Subvert expectations

  Scene 6 (161-208): ALL elements + Ride + Bass fully open
    → Real peak, but evolved

  Scene 7 (209-256): Swap percussion patterns, filter automation
    → Maintain energy through variation

  Scene 8 (257-288): Strip to Kick + Bass + Closed Hats
    → DJ tool exit

Step 4: Execute using Ableton MCP
  - Create clips in appropriate scenes
  - Apply automation for filters/volumes
  - Add groove to percussion
  - Configure send effects
```
