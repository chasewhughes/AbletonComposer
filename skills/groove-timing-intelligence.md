# Groove & Timing Intelligence Skill

## Purpose
Provides micro-timing, swing, polyrhythm, and groove psychology techniques to create hypnotic, human-feeling techno that avoids robotic grid-locked programming.

## Core Groove Philosophy

### The Human Element
Perfect quantization = boring, robotic techno. Professional tracks use intentional timing offsets to create urgency, swing, and hypnotic groove.

### Roger Linn's MPC Swing Principle
Swing delays even-numbered 16th notes, creating a "laid back" feel. At 130 BPM:
- 50% = No swing (perfectly quantized)
- 54% = Subtle looseness (barely perceptible)
- 62% = Looser than perfect triplets (funkier)
- 66% = Perfect triplet swing (maximum before odd)

### The Push & Pull Effect
Create tension by having some elements "rush" (early) while others "drag" (late). This creates groove through rhythmic conflict.

## Micro-Timing Strategies

### The Charlotte de Witte / Adam Beyer Approach

**Kick: 0ms (Grid-Locked)**
```
Purpose: The anchor, never moves
Reasoning: Everything else pushes/pulls against this
Result: Solid foundation for groove manipulation
```

**Closed Hats: -8ms to -12ms (Rushing)**
```
Purpose: Creates urgency and forward motion
Sweet spot: -10ms
Effect: "Pushing the beat," aggressive feel
When: Use on main groove hats, not fills
```

**Open Hats: +15ms to +20ms (Dragging)**
```
Purpose: Creates swing and laid-back feel
Sweet spot: +18ms
Effect: "Pulling back," creates space
When: Use on upbeat/off-beat hats
```

**Snare/Clap: +20ms to +30ms (Heavy Drag)**
```
Purpose: Weighted, "sinking" feeling
Sweet spot: +25ms
Effect: Makes hits feel powerful and deliberate
When: Use on backbeat elements (2 and 4)
```

**Bass: -2ms to +3ms (Subtle Variation)**
```
Purpose: Slight variation without losing lock
Sweet spot: +2ms (slightly behind kick)
Effect: Creates "glue" between kick and bass
Caution: Too much ruins low-end coherence
```

### Applying Micro-Timing in Ableton

**Method 1: Clip Delay (Entire Track)**
```
Use nudge_clip_timing tool:
  - Negative values = rush (early)
  - Positive values = drag (late)
  - Applied to entire clip
```

**Method 2: Note Timing (Per-Note Control)**
```
In MIDI clip:
  - Select individual notes
  - Nudge in piano roll view
  - Allows complex polyrhythmic patterns
```

**Method 3: Track Delay (Global Offset)**
```
Use track delay device:
  - Affects entire track
  - Good for consistent offset
  - Measured in milliseconds
```

## MPC Swing & Groove Templates

### Applying Groove in Ableton

**Swing 16ths (54-66%)**
```
Perfect for: Closed hats, shakers, hi-freq percussion
Amount:
  - Subtle: 54-57% (barely noticeable)
  - Standard: 60-62% (classic swing)
  - Heavy: 65-66% (funky, almost triplets)

Settings:
  - Timing: 10-20% (how much swing affects timing)
  - Velocity: 0-10% (optional velocity variation)
```

**Swing 8ths (54-62%)**
```
Perfect for: Slower-feeling grooves, basslines
Amount: Lower than 16ths for same effect
  - 54% = subtle
  - 60% = standard

Use when: Bass has 8th note rhythm
```

**No Swing (50%) + Micro-Timing**
```
Alternative approach:
  - Keep groove at 50% (no swing)
  - Apply manual micro-timing offsets
  - More control, less "template" feel
```

### Creating Custom Groove

**Charlotte de Witte Style Custom Groove:**
```
Based on micro-timing offsets:
  1. Downbeats (1, 2, 3, 4): 0ms (locked)
  2. 16th note offbeats: -8ms (rushing)
  3. "And" of beats (1.5, 2.5, 3.5, 4.5): +12ms (dragging)
  4. Other 16ths: Vary between -5ms and +8ms

Result: Hypnotic push/pull without obvious swing
```

## Polyrhythmic Programming

### The Hypnotic Loop Principle
Instead of 4-bar or 8-bar loops, use odd lengths that resolve over longer periods.

### Polymeter Techniques

**3/16 Loop (Against 4/4 Kick)**
```
Pattern length: 3 sixteenth notes
Against 4/4 kick: Resolves every 3 bars
Effect: Rushing, high-energy feel
Use on: Closed hats, shakers, high percussion
```

**5/16 Loop (Funky, Off-Kilter)**
```
Pattern length: 5 sixteenth notes
Against 4/4 kick: Resolves every 5 bars
Effect: Funky asymmetry, keeps ear engaged
Use on: Percussion loops, melodic elements
Most versatile: Good balance of odd/hypnotic
```

**7/16 Loop (Deep Trance)**
```
Pattern length: 7 sixteenth notes
Against 4/4 kick: Resolves every 7 bars
Effect: Very hypnotic, long evolution
Use on: Atmospheric textures, subtle percussion
Caution: Can feel "lost" if too prominent
```

**13/16 Loop (Extreme Hypnosis)**
```
Pattern length: 13 sixteenth notes
Against 4/4 kick: Resolves every 13 bars
Effect: Maximum hypnotic depth
Use on: Background textures only
Caution: Can confuse dancers if too loud
```

### Implementing Polymeters in Ableton

**Method 1: Clip Loop Length**
```
1. Create MIDI clip
2. Set loop length to odd 16th count:
   - 3/16 = 0.75 beats
   - 5/16 = 1.25 beats
   - 7/16 = 1.75 beats

3. Program pattern within loop
4. Let clip cycle against 4/4 kick
```

**Method 2: Unlinked Clip Envelopes**
```
1. Create standard 4-bar clip
2. Add automation envelope
3. Set envelope loop length differently:
   - Clip: 4 bars
   - Envelope: 3 bars
   - Result: Envelope cycles at different rate
```

### Polymeter Usage Guidelines

```
- Never use polymeter on kick (always 4/4)
- Use ONE polymeter at a time (not multiple)
- Make polymeter element ~30% volume of main groove
- Introduce polymeter after 32-64 bars (not immediately)
- Remove polymeter before breakdowns (can confuse)
```

## Velocity Variation (Humanization)

### Dynamic Velocity Programming

**Closed Hats:**
```
Pattern: 16th notes
Downbeats (1, 2, 3, 4): Velocity 100-105
Offbeats (e, &, a): Velocity 85-95
Ghost notes: Velocity 60-70 (occasional)

Effect: Natural dynamics, not machine-gun hats
```

**Open Hats:**
```
Pattern: Upbeats (2, 4) or syncopated
Primary hits: Velocity 90-100
Secondary hits: Velocity 70-80
Swing hits: Velocity 105-115 (accent the drag)

Effect: Emphasizes swing, adds expression
```

**Bass:**
```
If using multiple notes (not just one):
Root notes: Velocity 115-127 (strong)
Passing notes: Velocity 95-105 (lighter)
Ghost notes: Velocity 80-90 (texture)

Effect: Melodic interest without velocity
```

### Velocity Randomization

**Good Randomization:**
```
Range: ±10 velocity points
Apply to: Hi-hats, shakers, percussion
Avoid: Kick, bass (needs consistency)
```

**Bad Randomization:**
```
Range: ±30+ (too chaotic)
Apply to: Everything (loses dynamics)
Result: Messy, not "human"
```

## Advanced Groove Techniques

### The "Pocket" Technique

**Creating Space in the Groove:**
```
When stab/lead plays:
  - Reduce hat velocity -15 points
  - Slightly delay hats +3ms
  - Creates "pocket" for stab to sit in

When bass has busy pattern:
  - Simplify hat pattern
  - Remove 16th note fills
  - Lets bass complexity shine
```

### Groove Evolution Over Time

**Intro (Bars 1-32):**
```
Groove: Locked, minimal swing
Micro-timing: Only -5ms on hats
Purpose: Establish solid foundation
```

**Build (Bars 33-96):**
```
Groove: Add swing (60%)
Micro-timing: Increase to -10ms (hats)
Purpose: Creates building energy
```

**Peak (Bars 97+):**
```
Groove: Maximum swing (62-65%)
Micro-timing: Extreme offsets (-12ms / +20ms)
Purpose: Maximum hypnotic effect
```

### The "Fake Straight" Technique

**Subvert Expectations:**
```
Instead of swinging hats during peak:
  - Remove ALL swing (50%)
  - Lock hats to grid perfectly
  - But keep micro-timing on other elements

Effect: Sounds "harder" and more driving
When: Use for 16-32 bars during peak
Result: Creates contrast, then return to swing
```

## Integration with Ableton MCP

### Applying Groove:

```
Use apply_groove_with_amount:
  - groove_name: "MPC 16 Swing-62"
  - amount: 0.15 (15% - subtle)
  - track_index: Closed hats track
  - clip_index: Scene clip

Use set_groove_parameters:
  - timing: 0.15 (15% groove impact)
  - random: 0.08 (8% timing randomization)
  - velocity: 0.12 (12% velocity variation)
```

### Applying Micro-Timing:

```
Use nudge_clip_timing:
  - track_index: Closed hats (3)
  - clip_index: Current scene
  - offset_ms: -10 (rushing 10ms)

For multiple clips:
  - Loop through scenes
  - Apply same offset to all hat clips
```

### Creating Polymeters:

```
Use set_clip_loop_length:
  - track_index: Percussion loop
  - clip_index: Scene
  - loop_start: 0
  - loop_end: 1.25 (5/16 pattern)
```

## Quality Validation Checklist

- [ ] Kick remains grid-locked (0ms offset)
- [ ] Closed hats have rushing feel (-8 to -12ms)
- [ ] Open hats have dragging feel (+15 to +20ms)
- [ ] Swing applied to hi-freq percussion (54-66%)
- [ ] Bass timing is subtle (±3ms max)
- [ ] Velocity variation on hats (not static)
- [ ] Polymeter (if used) is subtle and not confusing
- [ ] Groove evolves over arrangement (not static)
- [ ] No micro-timing "fights" the mix
- [ ] Overall feel is hypnotic, not robotic

## Example Decision Flow

```
User: "The track sounds robotic and stiff"

Step 1: Identify grid-locked elements
  - Check: All elements quantized to grid
  - Problem: No human feel, no groove

Step 2: Apply micro-timing strategy
  Kick (Track 0):
    - Keep at 0ms (anchor)

  Closed Hats (Track 3):
    - Apply -10ms offset (rushing)
    - Reason: Creates urgency

  Open Hats (Track 4):
    - Apply +18ms offset (dragging)
    - Reason: Creates swing

Step 3: Apply MPC swing
  - Groove: "MPC 16 Swing-62"
  - Amount: 15% (subtle)
  - Apply to: Both hat tracks

Step 4: Add velocity variation
  Closed Hats:
    - Downbeats: 100
    - Offbeats: 85
    - Ghost notes: 65 (sparse)

  Open Hats:
    - Primary: 95
    - Secondary: 75
    - Accents: 110 (on drag beats)

Step 5: Optional - Add polymeter
  Create new percussion track:
    - 5/16 loop pattern
    - Volume: -12dB (subliminal)
    - Adds hypnotic layer

Result: Track has human groove, not robotic feel
```
